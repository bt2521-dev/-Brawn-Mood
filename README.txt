BROWN MOOD — проста версія (усі файли в одній папці, без підпапок)

Завантаження на GitHub:
  1. Розпакуйте архів.
  2. У репозиторії: Add file -> Upload files -> "choose your files".
  3. Відкрийте розпаковану папку, натисніть Ctrl+A (виділити все) і Відкрити.
     Усі файли завантажаться за раз (їх менше 100).
  4. Commit changes. Потім Settings -> Pages -> гілка main, папка / (root).
Файли .nojekyll може не показатись у списку — це нормально (він прихований).
